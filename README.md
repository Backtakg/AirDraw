# AirDraw ✦

Draw and write in the air using your webcam and hand tracking.

## Features

- Real-time index-finger tracking in the browser
- Pinch thumb + index finger to draw
- Multiple neon colors
- Air eraser
- Undo / redo
- Clear canvas
- Save artwork as PNG
- Controls live inside the camera/AR screen
- No backend or account required
- Camera processing stays in the browser

## Run

Use the GitHub Pages deployment over HTTPS so the browser can request camera access.

## Tech

- HTML
- CSS
- Vanilla JavaScript
- MediaPipe Hands
- Canvas 2D
- WebRTC camera API

The hand-tracking runtime and model assets are loaded from the public jsDelivr CDN at runtime.
